Как резать цену (2 рычага)

  • Ресёрчер не на каждый вопрос, а точечно (где нужна свежая цифра) → итог падает со ~130к до ~65к (вдвое).
  • Микс моделей: дешёвый Flash на 1–3, 5; ресёрчер (6) на Haiku; сильная модель (Sonnet 5) — только на 3 ревьюера (7–9) → ~$0.15–0.20 за вопрос — почти как Flash, но с качеством ревью Claude.

⏱ Сроки по категориям 🤖 ИИ-Лайв (из новостей)

Это категории, которые генерирует ИИ из новостей. Для каждой задай срок (число + единица), до которого событие должно разрешаться. Если в новости есть конкретная дата (встреча, заседание) — срок ставится точно по ней. Правило ниже — для случаев, когда даты в новости нет.

🔴 Лайв-каналы авто-категории по времени

Каждый канал — «Лайв {категория} · {время}» (напр. «Лайв Акции · 5 минут») генерит прогноз «какая {категория} будет выше за {время}». 🟢 = включён. Регулятор «выдача раз в …» — как часто выпускать, редактируется. По умолчанию: раз в час по 1.

Включает/выключает участие лайв-каналов в генерации. Общий запуск всего — кнопка «Старт» в «Настройки генерации». «Все категории» — вкл/выкл сразу все каналы галочками.

🖼 Генерация картинок провайдер + тест

Выбери сервис (чип = активный провайдер, зелёный). Картинки тянутся один раз, конвертируются в WebP и кэшируются. Жми «Сгенерировать» и смотри время/формат.
