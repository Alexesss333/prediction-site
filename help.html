⚙ В админку 👁 Лента

Что это

Сайт-прогнозы (как Polymarket): лента вопросов о будущем с вариантами ответа. Админка управляет тем, какие прогнозы создаются и как.

Два вида прогнозов

🤖 ИИ (из новостей)⚙️ Код (рынки)
ЧтоВопросы из реальных новостейИгры «вверх/вниз» по активам
Кто делаетНейросеть GeminiКод по шаблонам, без ИИ
Лимиты/деньгиДа, тратит запросы GeminiНет, бесплатно
Пример«Примет ли ЕС новый пакет санкций?»«Будет ли BTC выше $102 000 через 1 час?»

С чего начать

  • 1. Вставь Gemini-ключ (блок «📰 Новости → события» → поле ключа → «＋ Добавить ключ»). Бесплатный ключ — на aistudio.google.com/apikey (начинается с AIza). Можно несколько — при исчерпании берётся следующий.
  • 2. Включи галочку «Авто-поток» — сайт сам собирает новости и делает события.
  • 3. Включи рынки: блок «⚙️ Рынки» → «Создать/обновить рынки» → включи нужные интервалы.
  • 4. Открой ленту — прогнозы появятся по вкладкам.

📰 Новости → события (ИИ)

Gemini-ключи

Можно несколько, пробуются по очереди. 🟢 работает 🔴 лимит/ошибка. «↻ Сбросить статусы» — если лимит восстановился.

Модели

Пробуются сверху вниз; если у одной лимит — берётся следующая. Клик — вкл/выкл.

Источники

Откуда брать новости. Одна строка = один источник: тема (слова → поиск Google News) или прямая RSS-ссылка. Сбор новостей бесплатный.

🎯 Критерии важности

По ним модель оценивает все новости и берёт самые важные. Тут описываешь, что важно, а что отсеивать.

📝 Правила генерации события

Как формулировать вопрос (длина названия, число вариантов, стиль). Одно правило — одна строка. Именно сюда пиши «название ≤ N символов». Модель считает длину приблизительно — ставь реалистично, ≤50–60.

📊 Расход Gemini

Сколько запросов за сутки и сколько осталось. Сутки — по тихоокеанскому времени (как сброс у Google). Токены на лимит не влияют.

Дашборд (3 окна)

📥 найдено — прочитано новостей · ⭐ важных — отобрано · 📤 событиями — стало прогнозами. Клик по окну раскрывает список. «🔎 Прогнать сейчас» — прогон вручную.

⏱ Сроки по категориям (ИИ)

Для каждой ИИ-категории — срок диапазоном (от–до): число + единица. Модель выбирает срок в этом диапазоне по смыслу новости. Если в новости есть конкретная дата — срок ставится точно по ней.

⚙️ Рынки (код, бесплатно)

  • «Создать/обновить рынки» — заводит расписания (6 рынков × 8 интервалов + битвы), выключенными.
  • «▶ Включить все» / «⏸ Выключить все». Точечно — в блоке «♾ Авто-генерация».
  • ⚠️ Короткие интервалы (5м/15м) дают много событий — лучше включать 1ч/1д.
  • Крипта — реальные цены Binance + авто-проверка исхода (✅/❌). Остальные рынки — пока симуляция.

Остальные блоки

  • 🖼 Логотипы — картинки, которые подставляются на карточки рынков.
  • ♾ Авто-генерация — расписания поштучно (Старт/Стоп/✕) + добавить своё.
  • Ручная генерация — сделать события разово.
  • ➕ Своя категория — добавить свою тему.

Лимиты и деньги (Gemini)

  • Сбор новостей и код-рынки — бесплатно.
  • Тратят лимит только ИИ-действия: 1 оценка важности = 1 запрос, 1 ИИ-событие = 1 запрос.
  • Бесплатный лимит ≈ 500 запросов/сутки на модель. Больше — добавь ключи (каждый = свой лимит) или включи платный тариф.

Частые вопросы

  • Правило длины/вариантов не работает — пиши его в «📝 Правила генерации события», не в «Критерии важности».
  • Лента хаотична — уменьши «Прогнозов на категорию» или отключи лишние короткие интервалы рынков.
  • Ключ красный — проверь, что скопирован полностью (AIza…), включён «Generative Language API», или лимит на сегодня исчерпан.
  • Событий нет — включён ли авто-поток и рабочий ключ; для рынков — включены ли расписания.
